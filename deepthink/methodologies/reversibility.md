# 可逆性判断(Reversibility / Type 1 vs Type 2 Decisions)

**一句话**:决策分两种——可逆的(Type 2,双向门)和不可逆的(Type 1,单向门)。**两者应该用完全不同的决策方式**。多数人把可逆决策做得太慢,把不可逆决策做得太快。

---

## 适用场景

- **任何决策**——这通常是其他决策方法论之前的"过滤器"
- 当你不确定"该花多少时间做这个决定"时
- 当你纠结/焦虑某个决策时——往往是因为没识别清是哪种类型

## 不适用场景

- 纯执行性任务(无决策成分)
- 已经做了的决策(应该转去做"如何止损/巩固")

## 互补方法论

- **+ Pre-mortem**:确认是 Type 1(不可逆)的话,Pre-mortem 是必做的
- **+ 机会成本**:Type 2 的快速决策,关键是想清"不做这个,会错过什么"
- **+ 二阶思维**:可逆性判断本身就是看二阶——撤回行动的代价是多少

## 冗余方法论

- 无明显冗余;通常作为其他方法论的前置过滤

---

## 执行步骤

### 1. 把决策准确描述清楚

写下要做的决定。不要含糊。

> 例:"要不要把我现在用了 3 年的公司域名从 xxx.com 换成 yyy.com"

### 2. 三问可逆性

**问题 1:做完之后,撤回需要多大成本?**
- 撤回 = 完全回到决策之前的状态
- 成本包括:钱、时间、关系、机会、声誉

**问题 2:撤回过程会留下什么"疤痕"?**
- 即使撤回了,是否还有遗留影响?(用户记住了、市场印象改了、关系裂了)

**问题 3:在决策中获得的信息,撤回后是否能反过来用?**
- 这一点经常被忽略——很多 Type 1 决策的痛点不是"无法回去",而是"回去后失去了走出去的可能"

### 3. 归类

根据三问的答案,把决策归到三种里:

| 类型 | 特征 | 决策方式 |
|---|---|---|
| **Type 2(双向门)** | 撤回成本低、无疤痕、可重做 | **快**:60% 信息就行动,边做边调整 |
| **Type 1.5(部分可逆)** | 撤回有显著成本但可承受,有部分疤痕 | **中**:80% 信息再行动,设计止损方案 |
| **Type 1(单向门)** | 撤回几乎不可能,或代价摧毁性 | **慢**:>90% 信息+Pre-mortem+多人验证+不被时间压力推着做 |

### 4. 警惕"伪装"

很多决策**看起来是 Type 1 实际上是 Type 2**(给了人虚假的重要感)。

更危险的是:**有些决策看起来是 Type 2 实际上是 Type 1**——这些是真正的陷阱。

**常见伪装**:

| 看起来 | 实际上 | 例子 |
|---|---|---|
| 像 Type 1 | 是 Type 2 | "选哪个开发框架"——很多人纠结好久,实际可换 |
| 像 Type 2 | 是 Type 1 | "公开发表某个观点"——撤回了但截图还在;"和某人吵了一架"——道歉了但信任崩了 |
| 像 Type 2 | 是 Type 1 | "雇佣一个不太对的人"——理论可以解雇,实际成本极高(法律、士气、信任) |
| 像 Type 2 | 是 Type 1 | "降价"——降了之后涨回去几乎不可能(用户预期重置) |

### 5. 不对称错误

对 Type 1 决策,问:**做错的两个方向,哪边代价更大?**

- "做了但错了"的代价 vs "没做但本应该做"的代价

如果不对称严重,**朝代价小的方向选**。

> 例:癌症筛查——"假阳性"成本(多查一次)远低于"假阴性"成本(漏诊)。应该选择更敏感的筛查。

### 6. 给出建议

基于以上,给出:
- 这是哪种 Type
- 应该用多快/多慢的决策方式
- 主要的"伪装陷阱"是什么
- 不对称风险在哪边

---

## 质量自检

- ❌ 三问只问了一个或没问全
- ❌ 没识别任何"伪装"——大多数决策有伪装,完全没有说明分析过浅
- ❌ "类型"判断和"决策方式"不匹配(把 Type 1 用 Type 2 的方式建议,反之亦然)
- ❌ 没分析不对称错误——这是高价值的一步,跳过了说明分析不完整
- ❌ 结论是"再观察看看"——这本身就是一种决策(且通常是错的,因为它把 Type 2 当 Type 1 处理)

## Worked Example

**决策**:要不要在公司 Slack 公开反对一个高管刚发的策略?

### 三问

**1. 撤回成本**
- 撤回 = 删消息 + 道歉 + 私下沟通
- 评估:**中**(消息删了但已被截图传开的概率高)

**2. 撤回疤痕**
- 高管对你的印象重置:**严重**
- 团队对你的印象重置:看你怎么处理,可能正负皆有
- 评估:**显著且可能永久**

**3. 信息可用性**
- 反对带来的信息:看到其他人怎么反应、知道高管的真实底线 → 可复用
- 但代价是关系裂痕,**信息复用价值远低于代价**

### 归类
**Type 1**(单向门)——撤回成本高、疤痕严重、信息复用价值低

### 伪装识别
**典型"看起来 Type 2 实际 Type 1"**:Slack 消息看起来"删了就没了",但**职场记忆比技术更长**。一次公开反对,即使删了,会塑造你几年的形象。

### 不对称错误
- **做了但错**(反对了但策略其实是对的):代价 = 关系裂痕 + 形象受损 + 错过升职
- **没做但本应做**(策略真的错了你没说):代价 = 间接共谋 + 自我厌恶 + 可能项目失败

**评估**:做了但错的代价 > 没做但本应做的代价——因为前者是个人代价(直接),后者是分散代价(可推卸)。

### 决策建议
- 决策方式:**慢**——不要在情绪上来时立刻发
- 信息门槛:必须 95%+ 确定你的判断
- 替代方案:**Type 2 化处理**——先 1v1 私下找高管,这是双向门;如果私下沟通失败,再考虑是否要 Type 1
- 不要做:在情绪驱动下"凭一时正义感"发公开消息——这是最常见的"Type 2 假象+Type 1 现实"陷阱
- Pre-mortem:如果决定还是要公开反对,写 Pre-mortem——假设你公开反对了,半年后你被边缘化,失败的具体路径是?
