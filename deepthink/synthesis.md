# Synthesis(综合)

跑完所有方法论后,按以下四步综合,不要跳。

---

## 第一步:收敛结论

把所有方法论的输出过一遍,找出**指向同一方向**的结论。

### 怎么做

- 列出每个方法论的核心结论(每个 1-3 条)
- 找出 2 个及以上方法论都得到的相同/相近结论
- 这些就是"高置信"结论——多个独立视角都同意,可信度高

### 输出

```
## 收敛结论(高置信)

1. [结论 1]
   - 支持方法论:[方法论 A、方法论 B、方法论 C]
   - 为什么这些方法论都指向这里:[1-2 句简述]

2. [结论 2]
   - ...
```

---

## 第二步:分歧结论(关键)

找出方法论之间**打架**的地方,并解释原因。**不要强行调和**。

### 怎么做

- 找出有些方法论 A 说 X,另一个方法论 B 说 ¬X 的情况
- 分析为什么打架:
  - 是因为时间尺度不同?(一阶 vs 二阶往往打架)
  - 是因为视角不同?(利益结构 vs JTBD 可能打架——一个看推动者,一个看用户)
  - 是因为假设不同?(第一性原理 vs 经验主义往往打架)
  - 还是因为信息不对称?
- 分歧本身就是答案的一部分——它指出了真正的不确定性所在

### 输出

```
## 分歧结论(注意:这里是真正的不确定性)

### 分歧 1:[一句话描述分歧]
- 方法论 A 认为:[结论 A]
- 方法论 B 认为:[结论 B]
- **为什么会打架**:[分歧的根本原因]
- **这告诉我们什么**:[这个分歧本身揭示了什么——通常是"在 X 条件下 A 对,在 Y 条件下 B 对"]
- **如何解决**:[需要什么信息/条件,才能确定哪个对]
```

如果没有分歧,显式写"无重大分歧",但要警惕:**完全没有分歧通常意味着方法论选得不够多样,或者分析停留在表面**。这种情况要回头审一下选的方法论是不是太同质。

---

## 第三步:主导约束

找出整个问题里**最硬的那个约束**或**最关键的那个变量**。

### 怎么做

回顾全部分析,问自己:
- 如果只能改变一件事来改变结果,该改什么?
- 系统里最不能松动的限制是什么?
- 哪个因素一变,其他因素都会跟着变?(高杠杆点)

主导约束通常来自:
- 生物学(注意力、精力、时间)
- 物理(光速、能量守恒)
- 经济学(供需、激励)
- 心理学(认知带宽、损失厌恶)
- 网络(规模效应、需求方/供给方)
- 信息(谁知道什么)

### 输出

```
## 主导约束

最硬的约束是:[一句话]

为什么:[2-3 句说明这个约束如何贯穿全部分析]

如果这个约束松动了会怎样:[反事实推演]
```

---

## 第四步:行动建议 + 置信度

给出**可行动**的建议,并显式说明置信度的依据。

### 怎么做

- 把分析结论转成可行动的建议(谁、做什么、怎么做)
- 不要给"再观察看看"这种空话——除非这就是最优策略
- 置信度不是凭感觉打分,要有依据

### 置信度评估依据

| 置信度 | 判断标准 |
|---|---|
| **高(70%+)** | 多个方法论收敛、主导约束明确、无重大分歧 |
| **中(40-70%)** | 有部分收敛、有少量分歧但分歧原因清楚、主导约束基本明确 |
| **低(<40%)** | 方法论之间分歧大、主导约束不明确、依赖未知信息 |

### 输出

```
## 行动建议

### 短期(立即可做)
1. [具体行动]
2. [...]

### 中期(1-6 个月)
1. [...]

### 长期(策略层)
1. [...]

## 置信度

**整体置信度**:[高/中/低](X%)

**依据**:
- 收敛性:[多少方法论得到一致结论]
- 分歧程度:[有/无重大分歧,分歧是否能闭环]
- 信息完整度:列出来源分布(`[网络搜索]` X 项 / `[AI记忆]` Y 项 / `[AI推断]` Z 项),特别标出**哪些关键判断只靠 AI 推断、没有事实支撑**——这些是置信度的真正薄弱点

**需要更多信息才能提升置信度的地方**:
- [关键未知 1]
- [关键未知 2]
```

---

## 综合阶段的质量自检

跑完综合后,问自己:

- [ ] 收敛结论是否真的来自多个方法论,还是同一个方法论换说法?
- [ ] 分歧结论有没有被强行调和?(如果"看起来好像没有分歧",检查是不是分析太浅)
- [ ] 主导约束是不是真的硬?(如果"主导约束"可以轻易绕开,说明没找到真的)
- [ ] 行动建议是否真的"可做",还是套话?(读一遍,看每条建议能不能明天就开始)
- [ ] 置信度有没有真的依据?(不要凭感觉打分)
- [ ] 所有数字/时间/政策都标了来源吗?搜索来源带超链接,AI 记忆 / AI 推断分别标 `[AI记忆]` `[AI推断]`;如果三类混在一起没区分,整份分析的可信度无从评估
