# DeepThink Style Kit

> AI Output StyleKit — 风格套件 · v1.0

---

## 风格定位

**DeepThink** 是一套以学术咨询报告为灵感的视觉风格。

设计基调：纸张质感、克制的墨色系、精准的信息层级、适合长文阅读。推荐用于分析报告、研究结论、深度调研等内容较多的文档，内容较少时同样可以使用。

---

## 视觉语言

### 色彩语义

| 颜色 | 语义角色 |
|------|----------|
| 暖白 `#fbfbf8` | 页面底色，纸张感 |
| 主色绿 `#1f6f54` | 重点结论、正向信息、强调 |
| 警示琥珀 `#9a5a12` | 分歧、不确定、风险 |
| 链接蓝 `#275f8f` | 链接、次要信息 |
| 墨色系 `#161616 / #303030 / #656565` | 标题 / 正文 / 辅助文字 |

绿色 = 已确认的、正向的。琥珀色 = 需要注意的、存在争议的。这个映射在整套风格里保持一致。

### 可用组件

模板里内置了以下组件，**根据内容自由选用，不需要全部使用**：

| 组件 | 适合的内容 |
|------|-----------|
| 头部卡片 | 标题、元信息（日期、来源等） |
| 内容卡片（section） | 每个独立章节，加 `id` 自动进入目录 |
| 绿色结论块 | 核心结论、正向信息 |
| 琥珀警示块 | 分歧、风险、不确定 |
| 深绿约束块 | 最关键的限制或硬性条件 |
| 引用批注块 | 旁注、方法说明、引用 |
| 标签 | 来源标注、状态标记 |
| 大数字 + 进度条 | 置信度、关键指标 |
| 行动卡片组 | 行动建议、步骤、阶段 |
| 表格 | 数据对比、清单 |

克制感是这套风格的核心——不是每个段落都要加颜色块，留白和普通正文同样重要。

## 使用方式

把 `templates/report.html` 的链接或内容提供给 AI，附上你要美化的内容：

```
请读取这个 Style Kit 模板：
[report.html 的链接或内容]

把以下内容用这套风格渲染成 HTML 报告：
[你的 AI 输出内容]
```

模板文件的顶部注释里有完整的组件用法说明，AI 读取后即可直接使用。
